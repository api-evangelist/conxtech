# ConXtech

> ConXtech is a Pleasanton, California structural steel subcontractor that designs, fabricates, delivers and erects prefabricated steel building frames for commercial construction. Its ConX Systems line — the XL-400 and XR-200 chassis — uses patented collar-and-column connection technology with AISC 358 seismic prequalification, and the company reports erection three to five times faster than traditional structural steel methods across more than 20 million square feet of completed projects. ConXtech sells a physical building system, not software: as of 2026-08-09 it publishes no developer program, no public API, and no machine-readable contract of any kind.

## No developer surface

- ConXtech publishes no OpenAPI, AsyncAPI, GraphQL schema, MCP server, A2A agent card, SDK, or webhook catalog.
- `www.conxtech.com` is a WordPress marketing site. Its only machine-readable endpoint is the stock WordPress REST discovery document at `/wp-json/` (generic CMS plugin routes — Yoast, WP Engine, Avada, WP Mail SMTP — not a ConXtech product API). It is deliberately NOT registered as an API in this profile.
- `api.`, `developer.`, `developers.`, `docs.`, `portal.`, `my.` and `app.conxtech.com` all resolve but return an unconfigured-host 404 or a TLS mismatch. There is no developer portal behind any of them.
- No GitHub organization publishes ConXtech code; the `ConXTech` GitHub account has zero public repositories.
- ConXtech's engineering workflow consumes third-party BIM/CAD tools (Revit, Tekla) and it delivers Revit and Tekla models to project teams, but it publishes no plugin, extension, or programmatic interface of its own.
